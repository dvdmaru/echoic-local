安裝教學

需要 Apple Silicon（M1 以後）的 Mac、macOS 13 以上，以及約 2 GB 的空間（App＋語音辨識模型）。

  1. 下載

    到 GitHub Releases 下載 EchoicLocal-mac-arm64.dmg，打開後把「Echoic 本機版」拖到「應用程式」。

  2. 第一次開啟：macOS 說「無法打開」時，按「完成」，不要按「丟到垃圾桶」

    這個 App 沒有付費的 Apple 公證，用瀏覽器下載的版本第一次雙擊時，macOS 會跳出「無法打開」的警告，只有「丟到垃圾桶」和「完成」兩個按鈕。請按「完成」，再從下面三種做法挑一種打開它（最簡單的是到「系統設定 → 隱私權與安全性」按「仍要打開」）。每台電腦只需要做一次；之後在 App 裡更新也不會再被擋。

  3. 允許麥克風

    第一次錄音時 macOS 會問能不能用麥克風，按「允許」。錄音只存在你的電腦。

  4. 下載語音辨識模型

    按「下載語音辨識模型」，約 1.6 GB，從 Hugging Face 官方下載並比對 SHA256。裝過看懂 KanDong的話，通常已經有了，按鈕會直接顯示就緒。

  5. 錄音、轉逐字稿

    選錄音來源（實體會議選「只錄麥克風」，線上會議選「兩者都錄」），按「開始錄音」，結束按「停止」，再按「轉逐字稿」。與會者有填，說話人分離會準很多。

  6. （選用）產生摘要

    先安裝並登入 Claude Code。勾「轉完逐字稿後自動用 Claude 產生摘要」，或對單場按「產生這場摘要」。會用到你 Claude 方案的額度，所以預設不自動做。

第一次打開被擋：三種做法，你選

為什麼會被擋：Apple 要開發者每年付費加入開發者計畫、把 App 送去「公證」，macOS 才會直接放行。Echoic 本機版 目前沒有做這件事，所以用瀏覽器下載的版本會被標成「從網路下載、未經驗證」，第一次打開就被擋下來。 App 是開源的，程式碼都在 GitHub；每個安裝檔都附 SHA-256（Releases 頁的 SHA256SUMS.txt），可以自己比對檔案沒被動過。相信這個 App 再用下面任一種做法打開它，不相信就不要裝。

做法一：系統設定按「仍要打開」（不用終端機）

  1. 雙擊「Echoic 本機版」。macOS 說「無法打開」時，按「完成」（不要按「丟到垃圾桶」）。
  2. 打開「系統設定」→ 左邊選「隱私權與安全性」→ 往下捲到「安全性」。
  3. 會看到「已阻擋『Echoic 本機版』」，按旁邊的「仍要打開」（英文介面是 Open Anyway），輸入電腦密碼。
  4. 再跳一次確認視窗時，按「打開」。之後雙擊就能直接開。

「安全性」那裡沒有按鈕：先回去雙擊一次 App 再回來看，按鈕只會在被擋之後的一小時內出現。macOS 14 以前也可以對 App 按右鍵 →「打開」；macOS 15 起 Apple 拿掉了這條捷徑。

做法二：已經裝進「應用程式」了，用一行指令解除

打開「終端機」（在「應用程式 → 工具程式」），貼上這行、按 Return：

xattr -dr com.apple.quarantine "/Applications/Echoic 本機版.app"

這行只做一件事：拿掉 macOS 幫這個 App 貼的「從網路下載」標記。之後雙擊就能開。

做法三：不經過瀏覽器，用一行指令直接安裝

還沒下載、或想之後都這樣裝：打開「終端機」，貼上這行、按 Return：

curl -fsSL https://echoic.twtools.cc/install.sh | bash

這支安裝腳本只做五件事：從 GitHub Releases 下載最新版 dmg 與 SHA256SUMS.txt、比對 SHA-256（不符就停止，什麼都不裝）、把 App 複製到「應用程式」（覆蓋舊版）、卸載並刪掉暫存檔、打開 App。用 curl 下載的檔案不會被標成「從網路下載」，所以不會跳出警告。

想先看過內容再執行（比較謹慎的做法）：

curl -fsSL https://echoic.twtools.cc/install.sh -o install.sh
less install.sh
bash install.sh

只對你信任的網址這樣做。這個做法需要你的帳號能寫入「應用程式」資料夾（一般是管理者帳號）；不是的話請用做法一。

錄線上會議（對方的聲音）

macOS 預設錄不到電腦播出來的聲音，要先裝免費的 BlackHole 2ch 虛擬音源：

  1. 安裝 BlackHole 2ch。
  2. 打開「音訊 MIDI 設定」（在「應用程式 → 工具程式」），按左下角 + →「建立多重輸出裝置」，勾選 BlackHole 2ch 和你實際在聽的喇叭或耳機。
  3. 開會時，把系統的聲音輸出選成這個多重輸出裝置；你照樣聽得到，App 也錄得到。
  4. App 的錄音來源選「兩者都錄」。

常錯的名字：詞彙表

會議資料夾最上層有一份 詞彙表.md（第一次轉錄時自動建立）。一行一條：

- 正確寫法｜逐字稿常見錯寫（用、分開）｜備註

之後每場：正確寫法會提示給語音辨識、已知的錯寫直接換掉、摘要也照這裡寫。只有一個字的錯寫不會自動換，免得換錯。

轉完會得到什麼

  • transcript-by-minute.txt：逐分鐘、同一人連續發言合併，最好讀。
  • transcript.srt：字幕格式的逐字稿，可以拿去對影片。
  • summary.md：一句話、決議、待辦、數字表，每條附時間戳（有做摘要才有）。
  • audio.wav：原始錄音，不會被改動。

卡住了？

  • 打不開、說「無法打開」或「無法確認開發者」：看上面的三種做法。不小心按了「丟到垃圾桶」：到垃圾桶把 App 拖回「應用程式」，或重新下載。
  • 錄不到聲音：「系統設定 → 隱私權與安全性 → 麥克風」確認有允許 Echoic 本機版。
  • 沒錄到對方：輸出裝置要選多重輸出裝置，錄音來源要選「兩者都錄」。
  • 摘要按鈕是灰的：沒偵測到 Claude Code。安裝並登入後重新開啟 App。
  • 其他問題請到 GitHub 回報，附上會議資料夾裡的 whisper-server.log 或 ffmpeg.log（不要附錄音）。

下載 Mac 版Apple Silicon・macOS 13 以上・免費

Echoic 本機版：免費開源（MIT）的會議逐字稿工具。語音辨識使用 whisper.cpp、說話人分離使用 sherpa-onnx，都在你的電腦上執行。

錄音前請先取得與會者同意。逐字稿與摘要可能有錯，重要內容請回聽原音。
