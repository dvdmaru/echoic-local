安裝教學

需要 Apple Silicon（M1 以後）的 Mac、macOS 13 以上，以及約 2 GB 的空間（App＋語音辨識模型）。

  1. 下載

    到 GitHub Releases 下載 EchoicLocal-mac-arm64.dmg，打開後把「Echoic 本機版」拖到「應用程式」。

  2. 第一次開啟：右鍵 →「打開」

    這個 App 沒有付費的 Apple 公證，直接雙擊時 macOS 會擋下來。到「應用程式」資料夾，對它按右鍵 →「打開」，跳出的視窗再按一次「打開」。被擋住也沒關係：到「系統設定 → 隱私權與安全性」，在最下面按「仍要打開」。只需要做一次。

  3. 允許麥克風

    第一次錄音時 macOS 會問能不能用麥克風，按「允許」。錄音只存在你的電腦。

  4. 下載語音辨識模型

    按「下載語音辨識模型」，約 1.6 GB，從 Hugging Face 官方下載並比對 SHA256。裝過看懂 KanDong的話，通常已經有了，按鈕會直接顯示就緒。

  5. 錄音、轉逐字稿

    選錄音來源（實體會議選「只錄麥克風」，線上會議選「兩者都錄」），按「開始錄音」，結束按「停止」，再按「轉逐字稿」。與會者有填，說話人分離會準很多。

  6. （選用）產生摘要

    先安裝並登入 Claude Code。勾「轉完逐字稿後自動用 Claude 產生摘要」，或對單場按「產生這場摘要」。會用到你 Claude 方案的額度，所以預設不自動做。

錄線上會議（對方的聲音）

macOS 預設錄不到電腦播出來的聲音，要先裝免費的 BlackHole 2ch 虛擬音源：

  1. 安裝 BlackHole 2ch。
  2. 打開「音訊 MIDI 設定」（在「應用程式 → 工具程式」），按左下角 + →「建立多重輸出裝置」，勾選 BlackHole 2ch 和你實際在聽的喇叭或耳機。
  3. 開會時，把系統的聲音輸出選成這個多重輸出裝置；你照樣聽得到，App 也錄得到。
  4. App 的錄音來源選「兩者都錄」。

常錯的名字：詞彙表

會議資料夾最上層有一份 詞彙表.md（第一次轉錄時自動建立）。一行一條：

- 正確寫法｜逐字稿常見錯寫（用、分開）｜備註

之後每場：正確寫法會提示給語音辨識、已知的錯寫直接換掉、摘要也照這裡寫。只有一個字的錯寫不會自動換，免得換錯。

轉完會得到什麼

  • transcript-by-minute.txt：逐分鐘、同一人連續發言合併，最好讀。
  • transcript.srt：字幕格式的逐字稿，可以拿去對影片。
  • summary.md：一句話、決議、待辦、數字表，每條附時間戳（有做摘要才有）。
  • audio.wav：原始錄音，不會被改動。

卡住了？

  • 打不開、說「無法確認開發者」：照第 2 步用右鍵打開，或到「隱私權與安全性」按「仍要打開」。
  • 錄不到聲音：「系統設定 → 隱私權與安全性 → 麥克風」確認有允許 Echoic 本機版。
  • 沒錄到對方：輸出裝置要選多重輸出裝置，錄音來源要選「兩者都錄」。
  • 摘要按鈕是灰的：沒偵測到 Claude Code。安裝並登入後重新開啟 App。
  • 其他問題請到 GitHub 回報，附上會議資料夾裡的 whisper-server.log 或 ffmpeg.log（不要附錄音）。

Echoic 本機版：免費開源（MIT）的會議逐字稿工具。語音辨識使用 whisper.cpp、說話人分離使用 sherpa-onnx，都在你的電腦上執行。

錄音前請先取得與會者同意。逐字稿與摘要可能有錯，重要內容請回聽原音。
