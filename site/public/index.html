    自動分出 SPEAKER_00、01…；填了與會者，還會照人數分，摘要直接用人名。

    要摘要，再用你自己登入的 Claude 產生；預設關，不會偷偷用掉你的額度。

  • 🤝

    和看懂共用模型

    裝過看懂 KanDong 的人，通常不用再下載 1.6 GB 的語音辨識模型。

三步驟

  1. 錄選「只錄麥克風」或「兩者都錄」，按開始。
  2. 轉按「轉逐字稿」，等語音辨識和說話人分離跑完。
  3. 看打開資料夾：逐字稿、說話人、（選用）摘要都在裡面，也能直接當 Obsidian 筆記庫。

M4 MacBook Air 實測：語音辨識每小時錄音多半 4～6 分鐘，說話人分離另外要幾分鐘。

先說清楚做不到的

  • 沒有即時字幕，只做會後轉錄。
  • 目前只有 Apple Silicon Mac 版；Windows 版開發中。
  • 同音的專有名詞會寫錯，多人同時講話時說話人會分錯。重要內容請回聽原音。
  • App 沒有付費的 Apple 公證，第一次開啟要到「系統設定 → 隱私權與安全性」按「仍要打開」。

常見問題

要錢嗎？

不用。Echoic 本機版是 MIT 授權的開源軟體，語音辨識與說話人分離都在你的電腦上執行，沒有月費。摘要是選用功能，用的是你自己的 Claude 方案。

錄音會被上傳嗎？

不會。錄音、逐字稿都只存在你的電腦（預設在「下載項目」的 meetings 資料夾）。只有你打開摘要功能時，逐字稿文字才會送進你自己登入的 Claude Code；錄音檔本身一律不送。下載軟體與模型仍需要網路。

摘要會吃掉我的 Claude 額度嗎？

會，所以預設關。一小時的會議大約送出 4～5 萬字、拿回約 1 萬字（專名候選表與摘要各一次）。用 Pro（每月 US$20）方案時，一天做好幾場長會議可能比較快碰到用量上限。你可以只出逐字稿，想要哪一場的摘要再單獨按一次。

沒有 Claude 可以用嗎？

可以。沒裝 Claude Code 時只會產出逐字稿、說話人與時間戳，其他功能都一樣。
