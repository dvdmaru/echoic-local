免費・Mac・語音輸入

Echoic 輸入法：
按住講話，放開就打好字。

在任何 App 裡按住 ⌃⌥/ 講話，放開後台灣正體文字直接貼到游標位置。辨識用你自己的 OpenAI 或豆包（BytePlus）API key，邊講邊送，放開後約 0.3～1 秒出字。

下載輸入法Apple Silicon・macOS 13 以上・免費・0.2.1

和 Echoic 本機版不同：輸入法的辨識在雲端，講話時聲音會送到你選的服務。App 不含任何 API key，也不經過我們的伺服器。

用起來是這樣

  • 按住 ⌃⌥/ 講話：螢幕下方出現提示條（紅點＋音量），放開後顯示「辨識中」，接著文字貼進去。
  • Esc：講到一半想放棄。
  • ⌃⌥,：在 OpenAI 和豆包之間切換；選單列會顯示「〰 OpenAI」或「〰 豆包」。
  • 台灣正體：兩個引擎都直接出正體；萬一冒出簡體字，會自動轉回來。

安裝

  1. 下載 EchoicVoice-mac-arm64.zip，雙擊解壓縮，把「Echoic 輸入法」拖到「應用程式」。
  2. 第一次打開被擋（「無法打開」）：按「完成」，到「系統設定 › 隱私權與安全性」往下捲，按「仍要打開」。或用下面的指令。
  3. 允許麥克風；再到「系統設定 › 隱私權與安全性 › 輔助使用」打開「Echoic 輸入法」，才能自動貼上。
  4. 設定視窗會自己跳出來：貼上你的 API key，按「測試目前引擎」，看到 ✓ 就能用了。要開機自動啟動，在同一個視窗勾選。

不想經過瀏覽器（不會被擋）：打開「終端機」，貼上這行：

curl -fsSL https://echoic.twtools.cc/voice/install.sh | bash

這支安裝腳本只會下載安裝檔、比對 SHA-256（SHA256SUMS.txt）、複製到「應用程式」、打開。已經裝進「應用程式」才被擋，也可以用：xattr -dr com.apple.quarantine "/Applications/Echoic 輸入法.app"

申請 OpenAI API key（最簡單）

  1. 到 platform.openai.com/api-keys 登入（和 ChatGPT 訂閱是分開計費的，要另外在 Billing 儲值）。
  2. 按「Create new secret key」，複製 sk- 開頭那串。
  3. 貼到輸入法的「設定… › OpenAI」，按「測試目前引擎」。

申請豆包 Seed-ASR（BytePlus）

豆包語音辨識在海外由 BytePlus（字節跳動的國際雲）提供；火山引擎（中國版）不收海外用戶。

  1. 到 BytePlus 控制台註冊並完成付款設定。
  2. 進入語音服務（Seed Speech）的服務開通頁，開通串流語音辨識 2.0（Streaming ASR 2.0）。沒開通的話，測試會說「資源未授權」。
  3. 在同一個控制台的 API Key 頁建立一把 key，複製下來。
  4. 貼到輸入法的「設定… › 豆包（BytePlus）」，引擎選豆包，按「測試目前引擎」。

先說清楚做不到的

  • 目前只有 Apple Silicon（M1 以後）Mac、macOS 13 以上。
  • 要有網路；辨識費用依你自己的 OpenAI／BytePlus 帳戶計。
  • 快捷鍵目前不能改；沒有自動更新，新版請回這頁下載（App 選單有「下載新版…」）。
  • App 沒有付費的 Apple 公證，第一次打開要多做一步。

常見問題

要錢嗎？

App 免費。語音辨識是你自己的 OpenAI 或 BytePlus 帳戶在付費，依各家公布的語音辨識計價；講幾句話通常只是很小的金額，請以你帳戶的用量頁為準。

我講的話會送到哪裡？

按住快捷鍵時錄到的聲音，會直接從你的電腦送到你選的辨識服務（OpenAI 或 BytePlus），不經過我們的伺服器，我們也收不到。那家服務怎麼保存、會不會拿去訓練，依該服務的條款而定。公司或客戶的內容，請先確認可以交給第三方處理。

API key 存在哪？會不會被打包或上傳？

只存在你的電腦：~/.config/echoic-voice/openai-key、byteplus-key，權限設成只有你自己讀得到。App 本身不含任何 key；key 只會在辨識時送給它所屬的服務。log 只記長度與耗時，不記你講的內容。

OpenAI 和豆包差在哪？

我們用同一批錄音比過：兩邊選字準確度差不多。豆包（Seed-ASR 2.0）比較貼近原話、放開後出字較快（約 0.3 秒）；OpenAI（gpt-transcribe）句子比較順，偶爾會幫你改個字（約 0.8 秒）。兩把 key 都填，就能用 ⌃⌥, 隨時切換比較。

沒有自動貼上，要自己按 ⌘V？

要自動貼上，macOS 需要「輔助使用」權限：系統設定 › 隱私權與安全性 › 輔助使用，打開「Echoic 輸入法」。沒打開時文字會放在剪貼簿，提示條會告訴你。

快捷鍵可以改嗎？

目前固定是按住 ⌃⌥/（Control＋Option＋斜線）講話、Esc 取消、⌃⌥, 切換引擎。

為什麼 macOS 說「無法打開」？

和 Echoic 本機版一樣，這個 App 沒有付費的 Apple 公證，用瀏覽器下載的版本第一次打開會被擋。按「完成」，再照下面三種做法挑一種；之後更新不用再做。

可以離線用嗎？

不行，辨識在雲端做，要有網路。想完全離線，請用 Echoic 本機版做會後逐字稿。
